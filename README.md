# Eduard7central.github.io

Personal academic website of Eduardo Pagés, built with [Quarto](https://quarto.org).

- Edit the `.qmd` files (About = `index.qmd`, Research, Publications, CV).
- Preview: open the folder in RStudio and run `quarto preview` in the Terminal tab.
- Publish: run `quarto render` (output goes to `docs/`), then commit and push in GitHub Desktop.
- GitHub Pages setting: Settings › Pages › Deploy from branch › `main` / `docs`.
